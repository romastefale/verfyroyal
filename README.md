# verfyroyal

Um assistente para o Telegram criado para simplificar e organizar o processo de verificação oficial de perfis.

---

### O que ele faz?
O **verfyroyal** conecta administradores e membros de uma organização para facilitar a validação de contas, garantindo que perfis autorizados recebam o reconhecimento oficial de forma rápida e segura.

---

### Como funciona?
* **Membros:** Abrem uma conversa direta com o assistente para autorizar o contato.
* **Administradores:** Solicitam a validação das contas em um canal seguro e acompanham o andamento de todos os envolvidos.
